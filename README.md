# INFO 7375 — Irreducibly Human

**Fall 2026 · Predict → Build It → Use It → Ship It → Verify**

AI does the computing, drafting, and candidate generation it can usefully contribute. Humans practice the underlying mechanisms, evaluate evidence, maintain real relationships, and own authorized decisions. Every lesson and Assignment names the actual division for its artifact.

Claude Code access through NEU is assumed. Start with [NEU prerequisites](prerequisites/README.md) and [Northeastern's Claude portal](https://claude.northeastern.edu/). Independent readers need their own Claude Code-enabled account. Course implementations use Python's standard library; direct API credits are not required.

[Course syllabus](SYLLABUS.md) · [Assignments](assignments/fall-2026/README.md) · [Five-stage template](NEU-COURSE-TEMPLATE.md) · [Reading map](docs/reading-map.md) · [Submission templates](templates/README.md)
