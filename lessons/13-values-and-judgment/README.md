# Lesson 13 — An efficient answer still needs an end worth choosing

**Predict → Build It → Use It → Ship It → Verify**

Reading: [07 tier 7 existential and wisdom.md](../../chapters/07-tier-7-existential-and-wisdom.md) — “Wisdom is not the top of the knowledge hierarchy.” Tools: Claude Code and Python standard library. Prerequisites: prior lessons and retained predictions/evidence. Suggested pacing: one class session plus practice; Canvas supplies dates.

## Predict

Will changing the weights in a fictional decision matrix reverse the preferred option? Predict which value drives the result. Save an original expectation, confidence estimate, assumptions, and possible falsifier in PREDICTIONS.md before seeing the output. Add later observations without rewriting the original.

## Build It

Build a Python weighted-option calculator with normalized weights and sensitivity analysis. Keep the normative reasons for weights separate from the computation. Make an initial attempt before requesting a complete solution. Work in learning-artifacts/13-values-and-judgment/ with main.py, test_main.py, inputs, and outputs. Explain what the mechanism checks and what it cannot determine.

## Use It

Ask Claude to propose competing considerations in a harmless allocation problem. Choose and justify weights, then inspect a scenario where another reasonable weighting changes the outcome. Record date, model identifier as displayed, relevant prompts, commands, and actual results. Label fixtures, simulated participants, and hypothetical decisions. Claude Code is assumed; direct API calls are optional and may require separate credits.

## Ship It

Deliver decision matrix, sensitivity report, and contextual judgment memo. Include a README with exact run/test commands and source credits, plus the [prediction, contribution, Frictional, and verification records](../../templates/README.md). Package a local candidate for inspection; the [Assignment map](../../assignments/fall-2026/README.md) specifies final delivery.

## Verify

Check weights sum to one, reject non-finite values, and compare two weight sets by hand. A maximum score is not a proof of moral rightness or wisdom. Run checks on the packaged candidate. Record outcomes and remaining limits in VERIFICATION.md; revise and repeat Ship It → Verify when needed. Explain what changed in your understanding, without inventing difficulty or a required conclusion.

## Irreducibly Human

**AI should** calculate scenarios and articulate alternative considerations.

**Human should** justify the objective, consider affected interests, and own the bounded recommendation.

Record the actual split in CONTRIBUTIONS.md: what you did, what Claude contributed, what you accepted, changed, or rejected, and what still needs understanding or permission. A generated narrative does not establish human participation or consent.
