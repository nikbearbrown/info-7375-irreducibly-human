# Course decisions and boundaries

Fall 2026 is the current-term adaptation. Canvas supplies actual ten-day dates, section details, institutional policies, grade aggregation, late/resubmission rules, and quartile handling.

Fifteen lessons expand the seven-tier book into hands-on work. Every lesson and Assignment explicitly separates AI should from Human should. Core work uses Python and Claude Code; direct API calls and media production are optional. Ten-day Assignments use 60/10/10/20 scoring; lesson Assessments are ungraded.

The research handoff's rubric-freeze gate remains unratified by this conversion. Core exercises do not depend on that research gate: the index uses synthetic data and illustrative mappings. No research output, consent, signature, or empirical finding is fabricated. The capstone tests a specific division of labor rather than requiring a proof of a universal philosophical thesis.

The directory has no Git repository association at conversion time. Existing chapters, research, raw exports, papers, videos, and project state are untouched. Publication is a separate action requiring an explicit selection of appropriate teaching material.
