The implementation includes the specified Python mechanism and its applied reasoning artifact. A valid ledger cannot replace substantive evidence.

Submit matching versions to Canvas and the designated GitHub repository under fall-2026/first-name-last-initial/assignment-XX/. Include the final commit hash in Canvas. Videos and Brutalist are optional with no separate points. Classroom exposure indices are explicitly hypothetical and do not ratify the research rubric.
