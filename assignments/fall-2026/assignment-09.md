**Predict → Build It → Use It → Ship It → Verify**

Bundle [Lesson 14](../../lessons/14-exposure-and-evidence/README.md) into one submission. Lesson Assessments are ungraded practice.

## Predict

Would a different ability-to-tier mapping change an occupational exposure ranking? Predict the sensitivity before calculation. Preserve the original before receiving output or critique.

## Build It

Build a Python toy weighted index keyed by element_id, using explicitly synthetic abilities, weights, and exposure values. Version two alternative illustrative mappings and report coverage and ranking sensitivity.

## Use It

Ask Claude to audit the index's interpretation. Compare a task-exposure statement with an unsupported job-loss prediction. Use the local research handoff only as a provenance lesson; do not modify its pending rubric or claim official ratification.

## Ship It

Submit synthetic index, two illustrative mappings, coverage table, and interpretation limits. Include the Python implementation, tests, inputs, evidence, README, PREDICTIONS.md, CONTRIBUTIONS.md, FRICTIONAL.md, and VERIFICATION.md. Identify source material and real assistance. The final version goes to the designated GitHub location and Canvas.

## Verify

Hand-check a two-element weighted mean. Test missing element IDs, zero total weight, and duplicate records. Keep missing values distinct from zero. Do not substitute this toy mapping for rubric-v2-frozen.

Check the shipped candidate, record actual outcomes, and explain the bounded conclusion. Do not fabricate human participants, permissions, findings, or understanding. If a learning exercise uses a simulation, label it throughout.

## Division of labor

**AI should** compute and compare clearly labeled hypothetical indices.

**Human should** justify the construct, inspect coverage, and avoid claiming unratified research findings.

Explain deductions. The technical handoff row assesses usability and understanding; GitHub points assess delivery. Frictional assesses the actual process, not whether the result succeeded.
