**Predict → Build It → Use It → Ship It → Verify**

Bundle [Lesson 13](../../lessons/13-values-and-judgment/README.md) into one submission. Lesson Assessments are ungraded practice.

## Predict

Will changing the weights in a fictional decision matrix reverse the preferred option? Predict which value drives the result. Preserve the original before receiving output or critique.

## Build It

Build a Python weighted-option calculator with normalized weights and sensitivity analysis. Keep the normative reasons for weights separate from the computation.

## Use It

Ask Claude to propose competing considerations in a harmless allocation problem. Choose and justify weights, then inspect a scenario where another reasonable weighting changes the outcome.

## Ship It

Submit decision matrix, sensitivity report, and contextual judgment memo. Include the Python implementation, tests, inputs, evidence, README, PREDICTIONS.md, CONTRIBUTIONS.md, FRICTIONAL.md, and VERIFICATION.md. Identify source material and real assistance. The final version goes to the designated GitHub location and Canvas.

## Verify

Check weights sum to one, reject non-finite values, and compare two weight sets by hand. A maximum score is not a proof of moral rightness or wisdom.

Check the shipped candidate, record actual outcomes, and explain the bounded conclusion. Do not fabricate human participants, permissions, findings, or understanding. If a learning exercise uses a simulation, label it throughout.

## Division of labor

**AI should** calculate scenarios and articulate alternative considerations.

**Human should** justify the objective, consider affected interests, and own the bounded recommendation.
